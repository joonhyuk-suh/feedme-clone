# 메인 헤더 로그인 상태 표시와 다크 모드 glass 강화

메인 화면 헤더가 로그인 여부를 보여 주게 하고, 다크 모드에서 URL 입력창의 glass 효과가 잘 보이도록 강도를 높입니다.

## Linked sources

- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 헤더 버튼의 component·variant 선택과 semantic token 사용 원칙을 정합니다.
- [GLOSSARY.md](../../../GLOSSARY.md) — "표시 이름"의 정의를 정합니다.

## User-visible outcomes

- 로그인하지 않은 사용자는 메인 헤더에서 "로그인" 버튼을 보고, 눌러서 로그인한 뒤 메인 화면으로 돌아옵니다.
- 로그인한 사용자는 메인 헤더에서 자기 표시 이름과 로그아웃 버튼을 봅니다. 이름을 누르면 계정 설정으로 갑니다.
- 다크 모드에서 URL 입력창이 배경과 확실히 구분되는 유리 질감으로 보입니다.

## Approved scope

### 헤더: 로그인하지 않은 상태

- 지금의 "계정" 버튼을 "로그인" 버튼으로 바꿉니다.
- 누르면 로그인 화면으로 가고, 로그인을 마치면 메인 화면으로 돌아옵니다.

### 헤더: 로그인한 상태

- "계정" 버튼 자리에 표시 이름이 보입니다. 표시 이름이 비어 있으면 이메일 주소를 보여 줍니다.
- 표시 이름을 누르면 계정 설정 화면으로 갑니다.
- 표시 이름 옆에 로그아웃 버튼이 보입니다. 누르면 로그아웃되고, 메인 화면에 머문 채 헤더가 로그인하지 않은 상태로 바뀝니다.
- 계정 설정에서 표시 이름을 바꾸고 메인으로 돌아오면 헤더에 바뀐 이름이 보입니다.
- 테마 토글은 지금처럼 헤더 끝에 남습니다.

### 다크 모드 glass

- 다크 모드에서만 메인 화면 URL 입력창과 그 뒤 배경 빛의 강도를 높입니다. 라이트 모드는 지금 그대로 둡니다.
- 승인된 강도는 비교안 C "강함"입니다. 화면에서 다음이 보여야 합니다.
  - 입력창 뒤의 흐릿한 빛 덩어리가 어두운 배경 위에서 분명히 보입니다.
  - 입력창 자체에 옅은 밝은 반투명 채움이 있어 배경보다 한 단계 떠 보입니다.
  - 입력창 테두리가 또렷하고, 윗면에 가는 하이라이트가 있으며, 주변에 은은한 바깥 테두리 빛이 있습니다.
- 참고값(비교안 C): 빛 덩어리는 전경색 약 26% 농도로 지금보다 조금 크게, 입력창 채움은 전경색 약 10%, 테두리는 전경색 약 32%, 윗면 하이라이트는 전경색 약 20%입니다. 정확한 값은 구현에서 화면을 보며 맞춥니다.
- 입력 텍스트, placeholder, 변환 버튼, 잘못된 URL 오류 표시의 가독성은 지금보다 나빠지지 않아야 합니다.

## Acceptance criteria

1. 로그아웃 상태에서 메인 헤더에 "로그인" 버튼이 있고 "계정" 버튼은 없습니다.
2. "로그인"을 눌러 로그인하면 메인 화면으로 돌아오고, 헤더에 표시 이름과 "로그아웃" 버튼이 보입니다.
3. 표시 이름이 비어 있는 계정으로 로그인하면 헤더에 이메일 주소가 보입니다.
4. 헤더의 표시 이름을 누르면 계정 설정 화면이 열립니다.
5. 계정 설정에서 표시 이름을 바꾸고 메인으로 돌아오면 헤더에 바뀐 이름이 보입니다.
6. 헤더의 "로그아웃"을 누르면 메인 화면에 머문 채 헤더가 "로그인" 버튼 상태로 바뀝니다.
7. 다크 모드 메인 화면에서 입력창 뒤의 빛 덩어리와 입력창의 테두리·채움·윗면 하이라이트가 눈으로 분명히 구분되고, 비교안 C와 같은 인상을 줍니다.
8. 라이트 모드 메인 화면의 입력창과 배경은 변경 전과 같습니다.
9. 다크 모드에서 입력 텍스트, placeholder, 변환 버튼, 잘못된 URL 오류 문구가 모두 또렷이 읽힙니다.

## Settled constraints

- 로그인한 헤더는 "표시 이름(누르면 계정 설정) + 로그아웃 버튼"으로 구성합니다. 이름이 "계정" 버튼의 역할을 대신하고, 드롭다운 메뉴는 쓰지 않습니다. 사용자가 고른 구성입니다.
- 다크 모드 glass 강도는 비교안 C "강함"입니다. 사용자가 중간안보다 효과가 뚜렷한 쪽을 골랐습니다.
- 두 변경은 서로 독립적이지만, 둘 다 메인 화면 상단을 다듬는 작은 작업이라 사용자 결정으로 한 스펙에서 함께 다룹니다.

## Assumptions

에이전트가 정한 기본값이며, 사용자가 언제든 바꿀 수 있습니다.

- 요청의 "로그아웃을 할 수 없는 버튼"은 "할 수 있는 버튼"의 오타로 해석했습니다.
- 메인 헤더에서 로그아웃하면 로그인 화면으로 보내지 않고 메인 화면에 머뭅니다. 계정 설정 화면의 기존 로그아웃 동작은 바꾸지 않습니다.
- 표시 이름이나 이메일이 길면 헤더에서 말줄임으로 자르고, 좁은 화면에서도 로그아웃 버튼과 테마 토글이 가려지지 않게 합니다.
- [saved-articles](../saved-articles/spec.md)가 먼저 또는 나중에 들어오면, 로그인한 헤더 순서는 "저장한 글, 표시 이름, 로그아웃, 테마 토글"로 맞춥니다.

## Off-limits

- 라이트 모드의 glass 강도 — 사용자가 다크 모드 문제만 제기했습니다.
- 입력창 외 다른 화면 요소(결과 카드, 내보내기 패널 등)의 스타일 — 요청 범위 밖입니다.
- 로그인·회원가입 화면 자체와 계정 설정 화면 구성 — 이번 변경은 메인 헤더의 진입점만 다룹니다.

## Remaining risks

- 강한 glass는 빛 덩어리가 제목 주변까지 밝혀 화면이 다소 요란해 보일 수 있습니다. 구현 후 실제 화면에서 거슬리면 비교안 B 수준으로 낮출지 다시 정합니다.
