# 변환한 글 저장과 저장한 글 목록

로그인한 사용자가 변환 결과를 자기 계정에 저장하고, "저장한 글" 목록에서 골라 다시 읽고 내보내거나 삭제할 수 있게 합니다.

## Linked sources

- [docs/decisions/llm-handoff.md](../../decisions/llm-handoff.md) — 저장한 글의 상세 화면에서 쓰는 내보내기 문서 형식, 복사·다운로드·LLM 넘기기 동작을 정합니다. 변환 직후와 같은 규칙을 그대로 따릅니다.
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 저장 버튼, 목록, 상세, 삭제 확인, 빈 상태·오류 상태의 구성 원칙을 정합니다.
- [GLOSSARY.md](../../../GLOSSARY.md) — "변환 결과", "내보내기 문서", "저장한 글"의 정의를 정합니다.

## User-visible outcomes

- 로그인한 사용자는 변환 결과 화면에서 저장 버튼을 눌러 그 글을 자기 계정에 저장합니다.
- 이미 저장한 URL을 다시 저장하면 최신 변환 결과로 덮어쓰고, 덮어썼다는 사실을 안내받습니다.
- 로그인한 사용자는 헤더의 "저장한 글"에서 자기가 저장한 글 목록을 보고, 글을 골라 다시 읽습니다.
- 저장한 글의 상세 화면에서 변환 직후와 똑같이 복사하기, `.md` 다운로드, ChatGPT/Claude로 열기를 할 수 있습니다.
- 저장한 글을 확인 대화상자를 거쳐 삭제할 수 있습니다.

## Approved scope

### 저장

- 저장 버튼은 로그인한 사용자에게만 보입니다. 로그인하지 않은 사용자에게는 저장 버튼도, "저장한 글" 진입점도 보이지 않습니다.
- 저장하면 그 시점의 변환 결과(제목, 저자, 원본 URL, Markdown 본문)와 저장 시각을 보관합니다. 다시 볼 때 원본 페이지를 새로 가져오지 않습니다.
- 저장한 글은 원본 URL 하나당 하나입니다. 같은 URL을 다시 저장하면 내용과 저장 시각을 최신으로 바꿉니다.
- 저장 결과를 알림으로 알려 줍니다. 처음 저장한 경우와 기존 글을 덮어쓴 경우의 문구를 구분합니다.
- 저장을 마친 변환 결과에서는 버튼이 "저장됨" 상태로 바뀌어 같은 결과를 반복 저장하지 않습니다. 새로 변환하면 다시 저장할 수 있습니다.
- 저장에 실패하면 오류 알림을 보여 주고 버튼은 다시 누를 수 있는 상태로 돌아갑니다.

### 저장한 글 목록

- 로그인한 사용자의 헤더에 "저장한 글" 진입점이 생깁니다.
- 목록은 저장 시각이 최신인 글부터 보여 줍니다. 덮어쓴 글은 저장 시각이 갱신되므로 맨 위로 올라옵니다.
- 각 항목에는 제목, 원본 사이트 주소, 저장 날짜가 보이고, 누르면 상세 화면으로 갑니다.
- 저장한 글이 없으면 빈 상태를 보여 주고 메인(변환) 화면으로 가는 길을 안내합니다.

### 저장한 글 상세

- 변환 직후의 결과 화면과 같은 구성으로 원본 링크, 제목, 저자, 글자 수, Markdown 본문과 내보내기 패널을 보여 줍니다.
- 내보내기 패널의 동작은 변환 직후와 같고, 저장된 스냅샷으로 내보내기 문서를 만듭니다.
- 삭제를 누르면 되돌릴 수 없다는 확인 대화상자를 띄우고, 확인하면 삭제한 뒤 목록으로 돌아갑니다. 취소하면 아무것도 바뀌지 않습니다.
- 목록으로 돌아가는 길이 있습니다.

### 접근

- 저장한 글 목록과 상세는 로그인이 필요합니다. 로그인하지 않은 채 열면 로그인 화면으로 보내고, 로그인하면 원래 열려던 화면으로 돌아옵니다.
- 사용자는 자기가 저장한 글만 보고, 저장하고, 삭제할 수 있습니다.
- 없거나 다른 사용자의 글을 상세 주소로 열면 "글을 찾을 수 없습니다" 상태를 보여 주고 목록으로 가는 길을 안내합니다.

### 문구

- 메인 화면 푸터의 "변환한 내용은 저장하지 않습니다."는 이제 사실이 아니므로, 저장 버튼을 누를 때만 계정에 저장된다는 뜻으로 바꿉니다.

## Acceptance criteria

1. 로그인하지 않은 상태에서 URL을 변환하면 결과 화면에 저장 버튼이 없고, 헤더에 "저장한 글"이 없습니다.
2. 로그인한 상태에서 URL을 변환하고 저장을 누르면 새로 저장했다는 알림이 뜨고 버튼이 "저장됨"으로 바뀝니다.
3. 2의 글이 "저장한 글" 목록 맨 위에 제목, 원본 사이트 주소, 저장 날짜와 함께 보입니다.
4. 목록에서 글을 누르면 저장한 제목·저자·본문이 보이고, 복사하기·`.md` 다운로드·ChatGPT/Claude로 열기가 변환 직후와 같은 내보내기 문서로 동작합니다.
5. 같은 URL을 다시 변환해 저장하면 덮어썼다는 알림이 뜨고, 목록에는 그 URL의 글이 하나만 남은 채 맨 위로 올라오며 저장 날짜가 갱신됩니다.
6. 상세 화면에서 삭제를 누르고 확인하면 목록으로 돌아가고 그 글이 목록에서 사라집니다. 취소하면 글이 그대로 남습니다.
7. 저장한 글이 하나도 없으면 목록에 빈 상태와 메인 화면으로 가는 안내가 보입니다.
8. 로그인하지 않은 채 목록이나 상세 주소를 열면 로그인 화면으로 가고, 로그인하면 그 화면으로 돌아옵니다.
9. 사용자 A가 저장한 글은 사용자 B의 목록에 나오지 않고, B가 A의 글 상세 주소를 열면 "글을 찾을 수 없습니다"가 보입니다.
10. 메인 화면 푸터에 "변환한 내용은 저장하지 않습니다."가 더는 보이지 않습니다.

## Settled constraints

- 저장 버튼과 "저장한 글" 진입점은 로그인한 사용자에게만 보입니다. 사용자가 로그인 유도보다 화면을 단순하게 두는 쪽을 골랐습니다.
- 같은 URL은 하나만 저장하고 다시 저장하면 최신 내용으로 덮어쓰며, 덮어썼음을 안내합니다. 목록에 같은 글이 쌓이지 않게 하려는 사용자의 선택입니다.
- 삭제는 범위에 포함하고, 되돌릴 수 없다는 확인을 한 번 거칩니다.
- 상세 화면은 변환 직후와 같은 내보내기 기능을 제공합니다. 저장해 둔 글을 나중에 LLM에 넘기는 흐름을 한 화면에서 끝내기 위해서입니다.
- 저장한 글은 본인만 접근합니다. 기존 `profiles`와 같은 본인 전용 접근 방식을 따릅니다.

## Assumptions

에이전트가 정한 기본값이며, 사용자가 언제든 바꿀 수 있습니다.

- "같은 URL"은 변환 결과에 담긴 원본 URL 문자열이 정확히 같은 경우로 봅니다. 쿼리나 끝 슬래시만 다른 주소는 다른 글로 저장될 수 있습니다.
- 덮어쓰기 안내는 저장 후 알림 문구로 합니다. 저장 전에 미리 묻지 않습니다.
- 목록에는 페이지 나누기, 검색, 정렬 변경이 없습니다.
- 계정이 삭제되면 그 사용자의 저장한 글도 함께 지워집니다.
- 바꾼 푸터 문구의 정확한 표현은 구현에서 정합니다.

## Off-limits

- 로그인하지 않은 사용자의 임시 저장(브라우저 저장소 등)과 로그인 후 이어서 저장하기 — 사용자가 버튼을 숨기는 쪽을 골랐습니다.
- 저장한 글의 버전 기록, 편집, 태그·폴더, 검색, 공유 — 요청 범위 밖입니다.
- 원본 페이지를 다시 가져와 저장한 글을 자동 갱신하는 일 — 저장 시점 스냅샷이 계약입니다.
- 변환·추출 방식 변경 — [content-extraction](../../decisions/content-extraction.md)이 정하며 이번 작업과 무관합니다.

## Remaining risks

- URL을 문자열 그대로 비교하므로, 같은 글이 주소 표기만 달라 두 번 저장될 수 있습니다. 실제로 자주 생기면 URL 정규화 기준을 따로 정해야 합니다.
- 목록에 페이지 나누기가 없어 저장한 글이 아주 많아지면 목록이 느려질 수 있습니다. 강의용 범위에서는 받아들입니다.
