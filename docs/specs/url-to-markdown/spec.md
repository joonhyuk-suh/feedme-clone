# URL을 Markdown으로 바꿔 LLM에 넘기기

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude 새 대화로 바로 넘길 수 있게 한다.

승인된 화면: [prototype.html](prototype.html) — 화면 구성, 상태별 모습, 문구를 정한다. 프로토타입이 보여 주는 배치와 상태는 이 링크를 따르고, 이 스펙에 다시 옮겨 적지 않는다. 더미 데이터와 토스트로 흉내 낸 동작(실제 변환·복사·새 탭)은 참고용일 뿐 구현 코드가 아니다.

연결된 결정 계약:

- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 화면의 component, token, 상태 표현, 반응형 레이아웃을 정한다. 이 스펙은 그 규칙을 다시 적지 않는다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — 새 의존성(defuddle, DOM 구현)을 추가할 때의 버전 기준을 정한다.

## 사용자에게 보이는 결과

- 사용자는 URL 하나를 붙여넣고 변환하면, 광고·메뉴가 빠진 본문을 렌더링된 Markdown으로 읽을 수 있다.
- 결과 위에는 페이지 제목과 저자가 머리글로 보인다.
- 사용자는 결과를 클립보드로 복사하거나 `.md` 파일로 내려받을 수 있다.
- 사용자는 프롬프트(프리셋 또는 직접 입력)를 골라 결과를 ChatGPT나 Claude 새 대화로 바로 넘길 수 있다.
- 사용자는 화면을 다크 모드로 바꿀 수 있다.

## 범위

포함:

1. **입력**: URL 입력란, 변환 실행, 입력과 결과를 한 번에 비우는 지우기 버튼
2. **변환**: 입력한 URL의 페이지를 가져와 defuddle로 본문을 Markdown으로 추출
3. **결과 확인**: 제목·저자 머리글과 렌더링된 Markdown 본문
4. **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기
5. **프롬프트**: 프리셋 3개(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘)와 "직접 입력"
6. **다크 모드 토글**

## 수용 기준

입력

- URL을 입력하고 변환을 실행하면 변환이 시작되고, 끝날 때까지 진행 중임이 보이며 같은 요청을 다시 보낼 수 없다.
- 입력란에 내용이 있으면 지우기 버튼이 보이고, 누르면 입력값, 결과, 오류, 프롬프트 선택이 모두 처음 상태로 돌아간다.
- `https://`나 `http://`가 없는 주소(예: `stephango.com/saw`)는 `https://`를 붙여 변환한다.
- 웹 주소로 볼 수 없는 입력(빈 값, 공백이 섞인 문장, 도메인 없는 단어)은 변환 요청을 보내지 않고 입력란 옆에 잘못된 주소라는 안내를 보여 준다.

변환과 결과

- 본문은 defuddle로 추출하고 Markdown으로 받는다.
- 성공하면 페이지 제목이 머리글로 보인다. 저자가 있으면 제목과 함께 보이고, 없으면 저자 자리를 비우지 않고 아예 생략한다.
- 본문 Markdown은 원문이 아니라 렌더링된 형태(제목, 목록, 코드 블록, 인용, 표, 링크)로 보인다.
- 페이지를 가져오지 못하면(대상 사이트가 4xx·5xx를 돌려주거나 접속 자체가 실패) 오류 안내를 보여 주고, 화면이 깨지거나 빈 결과를 성공처럼 보여 주지 않는다. 예: `https://news.hada.io/`는 자동 접속을 403으로 막는다.
- 페이지는 열렸지만 추출된 본문이 비어 있으면 "본문을 찾지 못했다"는 별도 안내를 보여 준다.

내보내기 문서

- 복사하기, `.md` 다운로드, LLM으로 열기에 쓰는 문서는 모두 아래 형식이다. 저자 줄은 저자가 있을 때만 들어간다.

  ```markdown
  # {제목}

  저자: {저자}
  원본: {원본 URL}

  ---

  {본문 Markdown}
  ```

- 복사하기를 누르면 이 문서가 클립보드에 들어가고, 복사됐다는 피드백이 보인다.
- `.md` 다운로드를 누르면 이 문서가 `.md` 파일로 저장된다. 파일 이름은 페이지를 알아볼 수 있는 이름이며 OS에서 쓸 수 없는 문자를 포함하지 않는다.
- 복사하기와 `.md` 다운로드에는 프롬프트를 붙이지 않는다.

프롬프트와 LLM으로 열기

- 프롬프트는 "없음", 프리셋 하나, "직접 입력" 가운데 하나만 선택된다. 선택한 항목을 다시 누르면 해제되어 "없음"이 된다.
- 프리셋은 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘 세 개다.
- "직접 입력"을 고르면 프리셋 옆에 텍스트 입력란이 나타난다. 입력한 내용은 저장하지 않는다. 새로고침, 지우기, 새 변환 뒤에는 남아 있지 않다.
- "직접 입력"을 골랐는데 입력란이 비어 있으면 LLM으로 열기를 실행하지 않고 입력을 요청한다.
- ChatGPT로 열기와 Claude로 열기는 새 탭에서 해당 서비스의 새 대화를 연다. 보내는 내용은 프롬프트가 있으면 `프롬프트 + 빈 줄 + 내보내기 문서`, 없으면 내보내기 문서만이다.
- 보내는 내용이 URL에 담을 수 있는 길이면 새 대화 입력창에 그 내용이 채워진 채로 열린다.
- 보내는 내용이 그보다 길면 전체 내용을 클립보드에 복사한 뒤 새 대화를 열고, 입력창에 붙여넣으라는 안내를 보여 준다. 내용은 잘리지 않는다.

다크 모드

- 토글을 누르면 라이트와 다크가 바뀌고, 다시 방문해도 마지막 선택이 유지된다.

## 확정된 제약과 이유

- **본문 추출은 defuddle로 한다.** 사용자가 필수로 지정했다. 스크래치에서 defuddle 0.19.6을 Node 26.13.1, `defuddle/node`, `linkedom` 조합으로 돌려 일반 글, 위키 문서, X 게시물에서 제목·저자·Markdown 본문이 나오는 것을 확인했다.
- **페이지 가져오기와 변환은 서버에서 한다.** 브라우저가 다른 사이트의 HTML을 직접 가져오면 CORS에 막히기 때문이다.
- **대상 사이트의 응답 상태를 변환 전에 확인한다.** 403 안내문(HTML이 아닌 본문)을 그대로 `linkedom` + defuddle에 넘기면 `documentElement`가 null이라는 예외로 실패하는 것을 확인했다.
- **긴 내용은 클립보드로 넘긴다.** 사용자가 선택했다. 짧으면 바로 넘어가고, 길어도 본문이 잘리지 않게 하려는 것이다. 예시로 위키 문서 하나가 Markdown으로 약 34KB였다.
- **내보내기 문서에 제목·저자·원본 URL을 붙인다.** 사용자가 선택했다. LLM과 사람이 출처를 알 수 있게 하려는 것이다.
- **프롬프트는 LLM으로 열기에만 붙인다.** 사용자가 선택했다. 복사본과 `.md` 파일은 문서 그대로 남긴다.

## 가정 (바꿀 수 있음)

- LLM 새 대화는 `https://chatgpt.com/?q=…`와 `https://claude.ai/new?q=…` 형식으로 연다. 두 주소가 `q` 값을 입력창에 채우는지는 아직 직접 확인하지 않았다.
- "URL에 담을 수 있는 길이"의 기준은 구현에서 정하며, 두 서비스에서 실제로 채워지는 길이 안쪽으로 보수적으로 잡는다.
- 프리셋이 실제로 보내는 문장은 버튼 이름을 그대로 쓴다(예: "요약해줘").
- 다크 모드의 첫 방문 기본값은 OS 설정을 따른다.
- 변환 기록, 계정, 저장 기능은 없다. 한 번에 한 URL만 다룬다.
- 서비스 이름은 프로토타입대로 "FEED-ME"로 두고, 입력 영역의 큰 제목이 서비스 이름 역할을 한다.
- 결과 머리글에는 제목·저자와 함께 원본 사이트 주소와 대략적인 글자 수를 보여 준다. 보낼 내용 미리보기도 프로토타입대로 둔다.
- DOM 구현은 `linkedom`을 쓴다. 문제가 생기면 `jsdom`으로 바꿀 수 있다(같은 스크래치 검증에서 둘 다 동작).

## 범위 밖과 이유

- **로그인이 필요한 페이지, 스크립트로 그리는 페이지의 본문 추출**: 서버가 가져온 HTML에 본문이 없으면 "본문을 찾지 못했다"로 처리한다. 브라우저 렌더링을 서버에 두는 것은 이번 범위가 아니다.
- **봇 차단 우회**: 403 등으로 막은 사이트를 우회하지 않는다. 사이트의 의사를 존중하고 범위를 작게 유지한다.
- **defuddle.md 호스팅 API 사용**: 요청 수 제한과 유료 키가 생긴다. 라이브러리를 직접 쓴다.
- **프롬프트·변환 결과 저장, 공유 링크, 여러 URL 일괄 변환**: 요청에 없다.
- **스펙에 없는 보안 하드닝과 성능 방어**: 프로젝트의 검증·리뷰 예산(`AGENTS.md`)에 따라 범위 밖이다.

## 보류한 결정

없음. 화면 구성은 [prototype.html](prototype.html)로 승인됐다. 넓은 화면은 본문 왼쪽과 내보내기 패널 오른쪽, 좁은 화면은 내보내기 패널이 본문 위에 오는 구성이다.

## 남은 위험

- `chatgpt.com/?q=`, `claude.ai/new?q=`가 서비스 쪽 변경으로 입력창을 채우지 않게 되면 "바로 넘기기"가 동작하지 않는다. 이 경우에도 긴 글 경로(클립보드 + 붙여넣기 안내)는 동작한다.
- 봇 차단이 흔한 사이트(국내 커뮤니티, 일부 언론)는 대부분 실패 안내로 끝날 수 있다.
- 서버가 사용자가 입력한 임의의 URL을 가져오므로, 내부망 주소 요청 같은 악용 가능성이 남는다. 강의용 범위라 막지 않는다.
