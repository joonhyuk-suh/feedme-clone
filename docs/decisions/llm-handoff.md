# 변환 결과 내보내기와 LLM 넘기기

## Decisions

- 복사하기, `.md` 다운로드, LLM으로 열기는 모두 같은 내보내기 문서를 씁니다. 문서 머리에 제목, 저자(있을 때만), 원본 URL을 붙입니다.
- 프롬프트는 LLM으로 열기에만 붙입니다. 복사본과 `.md` 파일은 문서 그대로 둡니다.
- LLM 새 대화는 `https://chatgpt.com/?q=…`와 `https://claude.ai/new?q=…`로 엽니다.
- 보낼 내용이 URL에 담기에 길면 전체를 클립보드에 복사하고 새 대화를 연 뒤 붙여넣기를 안내합니다. 내용을 자르지 않습니다. 길이 기준은 `lib/feed-me/llm.ts`의 `MAX_ENCODED_QUERY_LENGTH`가 정합니다.

## Why

제목·저자·원본 URL을 붙이면 LLM과 사람이 출처를 알 수 있습니다. 긴 글을 잘라 URL에 넣으면 본문이 손실되므로 클립보드로 넘깁니다. 위키 문서 하나가 Markdown으로 약 34KB여서 긴 경우가 드물지 않습니다.

## Reconsider when

- 두 서비스가 `q` 파라미터로 입력창을 채우지 않게 되면 바로 넘기기 경로를 다시 정합니다. 이때도 클립보드 경로는 동작합니다.

## Still-rejected alternatives

- 긴 내용을 URL 길이에 맞게 잘라 넘기는 방식 — 본문이 손실됩니다.
